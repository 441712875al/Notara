# Notara

一款免费、开源的 macOS Markdown 编辑器，Typora 的本地替代方案。

即时渲染的所见即所得写作体验，配合多标签页、工作区文件树、图片粘贴、离线导出与主题系统，以及一套对「未保存文字」近乎偏执的保护机制。

- **技术栈**：Electron · vditor（即时渲染）· React 19 · TypeScript
- **平台**：macOS（Apple Silicon 与 Intel）
- **状态**：v0.1.0 首个发布版本

---

## 特性

- **即时渲染** —— 光标所在行显示源码，其余行实时渲染为富文本，接近 Typora 的写作体验
- **工作区 + 多标签页** —— 一个窗口管理一个文件夹，文件树、右键新建/重命名/删除
- **自动保存** —— 停止输入 500ms 自动落盘，关键时机立即保存，写不进去绝不静默丢弃
- **图片粘贴 / 拖拽** —— 自动存到笔记旁的 `assets/`，正文插入相对路径引用
- **离线导出** —— HTML（样式与图片全部内联）、PDF（A4 分页）
- **主题系统** —— 跟随系统 / 亮色 / 暗色，支持自定义 CSS 与 Typora 主题包导入
- **代码块** —— 就地编辑、语法高亮、一键复制
- **大纲面板** —— 标题层级导航，点击跳转
- **状态恢复** —— 工作区、标签页、窗口位置、侧栏宽度下次启动全部还原

## 安装

### 构建 dmg（日常使用）

```bash
npm install
npm run dist
```

产物位于 `release/` 目录，生成 Apple Silicon（arm64）与 Intel（x64）两个 dmg 安装包。双击 dmg，将 Notara.app 拖入「应用程序」即可。

> 本地构建未做代码签名，首次打开若被 Gatekeeper 拦截，右键 Notara.app →「打开」。

### 源码开发模式

```bash
npm install
npm run dev
```

开发模式带热重载与 DevTools。

## 快速上手

1. 启动后点击「打开文件夹」，选择你的笔记目录
2. 点开一篇笔记开始写作 —— 无需手动保存
3. 截图后直接 ⌘V 粘贴，图片自动归档
4. ⌘E 导出 PDF，⌘⇧E 导出 HTML
5. ⌘Q 退出，下次启动一切恢复原样

## 功能说明

### 文件与工作区

- ⌘O 打开文件或文件夹；命令行 `open -a Notara ~/my-notes` 亦可
- 文件树右键：新建文件 / 新建文件夹 / 重命名 / 删除（移入废纸篓）
- 只显示 Markdown 文件与目录，隐藏 `.` 开头的文件与 `assets/` 目录

**外部变更处理** —— Notara 实时监听文件系统：

| 磁盘变化 | 标签状态 | 行为 |
|---|---|---|
| 内容被修改 | 无未保存修改 | 自动重载新内容 |
| 内容被修改 | 有未保存修改 | 弹窗二选一：保留我的版本 / 加载磁盘版本 |
| 文件被删除 | 任意 | 标记「已删除」，保存时引导另存为 |

### 编辑与自动保存

- 停止输入 **500ms** 后防抖写盘；切换标签、失焦、关闭、退出时立即 flush
- 保存失败弹 toast 提示，脏标记保留，下次输入自动重试；标签标题下的圆点表示有未保存修改
- ⌘S 保存，⌘⇧S 另存为（也是「未命名」文件的唯一保存途径）

### 标签页

- 中键点击关闭；⌘⇧[ / ⌘⇧] 循环切换；⌘1–⌘9 直达第 N 个标签
- ⌘N 新建未命名文件，⌘⇧N 新建窗口，⌘W 关闭当前标签
- 关闭有未保存修改的标签时，弹出「保存 / 不保存 / 取消」三态确认

### 图片

- ⌘V 粘贴或直接拖入图片文件，自动保存至笔记同目录 `assets/`（不存在则自动创建）
- 正文插入相对路径引用 `![](assets/xxx.png)`，笔记目录保持自包含、可整体移动
- 文件名含空格或中文时自动做 URL 编码

### 导出

- **⌘⇧E 导出 HTML**：样式与图片全部内联，断网可看，适合直接分享
- **⌘E 导出 PDF**：A4 分页，适合打印或存档

导出基于磁盘上的最新内容（含自动保存），产物落在原笔记旁。导出前文件须已保存。

### 主题

- 视图菜单 → 主题：跟随系统（默认）/ 亮色 / 暗色
- **自定义主题**：将 CSS 放入 `~/Library/Application Support/notara/themes/`，重启后出现在主题子菜单
- **导入 Typora 主题**：视图菜单 → 主题 → 导入 Typora 主题，自动完成变量桥接、选择器重写与资源迁移

### 数据安全

退出与关闭前，Notara 会强制写盘所有未保存内容；无法自动保存的标签（未命名、已被外部删除）逐个引导另存为，任一未落盘即中止退出。你的文字不会静默丢失。

## 数据存储

| 内容 | 位置 |
|---|---|
| 你的笔记 | 你自己的目录（Notara 永不复制、不搬家） |
| 粘贴的图片 | 笔记同目录 `assets/` |
| 主题与设置 | `~/Library/Application Support/notara/settings.json` |
| 自定义主题 | `~/Library/Application Support/notara/themes/*.css` |
| 窗口状态 | `~/Library/Application Support/notara/window-state.json` |
| 最近工作区 | `~/Library/Application Support/notara/recent.json` |

卸载 Notara 不会影响你的笔记；彻底清除应用数据可删除 `~/Library/Application Support/notara/`。

## 常见问题

**⌘N 新建的「未命名」文件，⌘S 没反应？**
未命名文件没有磁盘路径，⌘S 与 ⌘⇧S 都会弹出「另存为」对话框，选好位置即保存。

**粘贴图片没反应？**
未保存的新文件不能收图（图片需落到文件所在目录），先 ⌘⇧S 保存再粘贴。

**别的应用改了我的笔记？**
会自动重载；若你这边也有未保存修改，会弹冲突确认框，绝不静默覆盖任何一边。

**忘了保存就 ⌘Q 了？**
内容仍在。⌘Q 会先自动写盘所有已保存过的文件，只有「未命名」文件会弹确认框拦住你。

## 开发

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（热重载 + DevTools）
npm run typecheck  # TypeScript 类型检查
npm run dist       # 构建 + electron-builder 打 dmg
```

架构概览：

```
src/
├── main/            # 主进程：窗口、菜单、服务层（文件/工作区/监听/图片/导出/主题/状态）
│   └── services/    #   无状态服务函数，注入 userData 目录便于测试
├── preload/         # contextBridge：暴露类型化的 window.notara API
├── renderer/        # React 19 + zustand：UI、标签、编辑器、自动保存调度
└── shared/          # 主 / 渲染进程共享的类型契约
```

安全基线：`nodeIntegration: false` / `contextIsolation: true` / `sandbox: true`，渲染进程零 Node API，所有通信走校验过的 IPC。

## 已知限制与路线图

当前 v0.1 的已知限制：

- 本地构建无代码签名与公证，首次打开需手动放行
- mermaid 图表与公式渲染的懒加载资源需联网
- 多窗口的窗口状态各自记录，最后关闭者覆盖
- 暂无工作区内全局搜索

后续版本候选：帮助菜单、Word 导出（pandoc）、全局搜索、代码签名与 Homebrew 分发、asar 体积裁剪。
