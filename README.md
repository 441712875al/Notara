# Notara

免费、开源的 macOS Markdown 编辑器 —— 一个 Typora 的替代品。

即时渲染（所见即所得的写作体验）、多标签页、工作区文件树、图片粘贴、导出 HTML/PDF、暗色主题，以及不惜一切代价保护你未保存的文字。

- **技术栈**：Electron 33 + vditor（IR 即时渲染模式）+ React 19 + TypeScript
- **平台**：macOS（Apple Silicon 与 Intel）
- **许可**：源码构建，本地使用

## 安装与启动

### 方式一：安装 dmg（推荐日常使用）

```bash
npm install        # 安装依赖
npm run dist       # 构建并打包
```

产物在 `release/` 目录：

- `Notara-0.1.0-arm64.dmg`（Apple Silicon）
- `Notara-0.1.0.dmg`（Intel）

双击 dmg，把 Notara.app 拖进「应用程序」即可。本地构建未做代码签名，首次打开如遇 Gatekeeper 拦截：右键点 Notara.app →「打开」。

### 方式二：源码开发模式

```bash
npm install
npm run dev
```

开发模式带 DevTools（视图菜单）、热重载。

## 三分钟上手

1. 启动 Notara，看到欢迎页 → 点「打开文件夹」，选择你的笔记目录（或随便建一个）
2. 左侧文件树点开一篇笔记，开始打字 —— **不用管保存**，500ms 防抖自动落盘
3. 截图后直接 ⌘V 粘贴进正文，图片自动存到笔记旁的 `assets/` 目录
4. 写完 ⌘E 导出 PDF，或 ⌘⇧E 导出 HTML
5. ⌘Q 退出。下次启动，工作区、打开的标签、窗口位置全部恢复

## 窗口与界面总览

Notara 的窗口布局（macOS 隐藏式标题栏）：

```
┌────────────────────────────────────────────────┐
│ ●●●          [标签页栏]                 + 新建  │
├──────┬─────────────────────────────┬───────────┤
│ 文件 │                             │   大纲     │
│ 树   │        编辑区（即时渲染）      │  （⌘⇧O）  │
│ ⌘\   │                             │           │
└──────┴─────────────────────────────┴───────────┘
```

- **侧边栏（文件树）**：⌘\ 切换显隐
- **大纲面板**：⌘⇧O 切换显隐，点击标题跳转
- **编辑区**：vditor IR（Instant Rendering）模式 —— 光标所在行显示 Markdown 源码，其余行实时渲染成富文本，体验接近 Typora

Notara 有两种使用形态，窗口模型会自动适配：

- **工作区模式**：打开文件夹后，文件树可用，新建/重命名/删除都在这个目录内进行
- **单文件模式**：单独打开一个 .md 文件（无文件夹），只有标签页，没有文件树

## 文件与工作区

### 打开

- ⌘O：打开文件或文件夹（对话框）
- 欢迎页「打开文件夹」按钮
- 命令行：`open -a Notara ~/my-notes`，或对任意 .md 右键 → 打开方式 → Notara

### 文件树操作（右键菜单）

- **新建文件**：在当前目录创建 .md（不写扩展名会自动补 `.md`）
- **新建文件夹**
- **重命名**：原地改名
- **删除**：**移入废纸篓**（不是直接删除，可在废纸篓找回）
- 点击文件在标签页打开；点击文件夹展开/折叠

文件树只显示 Markdown 文件（.md / .markdown）与目录，隐藏以 `.` 开头的文件。`assets/` 图片目录不出现在树中，但导出时会正确内联。

### 外部变更（其他应用改了你的文件）

Notara 实时监听文件系统，分三种情况处理：

| 磁盘上的变化 | 你的标签状态 | Notara 的行为 |
|---|---|---|
| 内容被修改 | 干净（无未保存修改） | 自动重载新内容 |
| 内容被修改 | 有未保存修改 | 弹窗二选一：「保留我的版本」/「加载磁盘版本」（后者需二次确认丢弃本地修改） |
| 文件被删除/移走 | 任意 | 标签标记「已删除」，保存时会引导你另存为 |

### 窗口状态恢复

退出前 Notara 每秒记录一次：工作区路径、打开的标签、激活的标签、窗口位置大小。下次启动自动恢复。拔掉外接显示器后旧窗口位置若不可见，会自动回退到默认位置。

## 编辑与自动保存

### 自动保存（核心机制）

- 停止输入 **500ms** 后自动写盘（防抖）
- 切换标签、窗口失焦、关闭标签、退出应用时**立即**保存（flush）
- 保存失败（如文件被锁、磁盘满）：弹 toast「保存失败，已保留修改稍后重试」，脏标记保留，下次输入或 flush 自动重试
- 标签标题下的圆点 ● 表示有未保存修改

### 手动保存

- ⌘S：保存当前标签
- ⌘⇧S：另存为（也是**未命名文件**的唯一保存途径 —— 见[常见问题](#常见问题)）

### 格式快捷键

⌘B 加粗、⌘I 斜体、⌘⇧K 行内代码、⌘K 链接。其余 Markdown 语法（标题、列表、表格、代码块、公式、mermaid 图表）直接敲语法即可，IR 模式即时渲染。

## 标签页

- 点击切换；中键（滚轮按下）关闭
- **⌘⇧[ / ⌘⇧]**：向左/向右循环切换标签
- **⌘1 … ⌘9**：直达第 N 个标签
- ⌘W：关闭当前标签（有未保存修改时弹三态确认）
- ⌘N：新建未命名文件；⌘⇧N：新建窗口
- 关闭脏标签的三态确认：**保存** / **不保存** / **取消**（取消 = 不关了）

未命名文件（⌘N 创建的）在标签上显示「未命名」，保存时自动走「另存为」对话框。

## 图片：粘贴与拖拽

- **⌘V 粘贴**：截图后在编辑器里直接粘贴，或从浏览器/微信复制图片后粘贴
- **拖拽**：把图片文件拖进编辑器

图片自动保存到**当前笔记所在目录的 `assets/`** 文件夹（不存在会自动创建），正文插入相对路径引用 `![](assets/xxx.png)`，你的笔记目录保持自包含、可整体移动/同步。

注意事项：

- 图片文件名含空格或中文时会自动做 URL 编码，渲染不受影响
- **未保存的新文件**（还没另存为过）无法粘贴图片 —— 先 ⌘⇧S 给文件一个家
- 多张图片同时拖入会按顺序依次插入

## 大纲面板

⌘⇧O 或视图菜单「切换大纲」。面板列出当前文档的标题层级，点击任意标题，编辑区滚动定位。对长文档导航非常有用。

## 导出 HTML 与 PDF

- **⌘⇧E：导出 HTML** —— 生成与笔记同名的 `.html` 文件，样式与图片全部内联，**断网可看**，适合直接发给别人
- **⌘E：导出 PDF** —— A4 纸分页，适合打印或存档

两种导出都基于当前磁盘上的最新内容（含自动保存），导出的文件落在原笔记旁边（`笔记名.html` / `笔记名.pdf`）。导出内容是渲染后的正文，代码高亮、公式、表格均正常呈现。

注意：导出前文件必须已保存（未命名文件会提示「请先保存文件，再导出」）。

## 主题系统

视图菜单 → 主题，三个内置选项：

- **跟随系统**（默认）：随 macOS 外观自动切换
- **亮色** / **暗色**：编辑器与界面全套暗色主题（vditor 原生暗色渲染）

### 自定义 CSS 主题

把你自己的主题文件放进：

```
~/Library/Application Support/notara/themes/你的主题名.css
```

重启 Notara（或重开视图菜单）后，主题子菜单会出现「你的主题名」选项。CSS 变量参考内置定义（亮色/暗色变量集），可覆盖编辑器配色、字体、背景等。

主题选择持久化在 `~/Library/Application Support/notara/settings.json`。

## 退出与关闭：数据安全设计

Notara 对「你写的字不能丢」有强迫症级的处理：

### ⌘Q 退出

1. 广播 flush：所有窗口立即写盘未保存内容
2. 若有**无法自动保存**的标签（未命名文件、已被外部删除的文件），弹出确认框：
   - **保存**：逐个引导另存为（任一取消则整个退出中止）
   - **不保存**：明确放弃这些修改
   - **取消**：不退了，回到编辑器
3. 写盘验证：确认保存后再次校验，任何标签仍处于未保存状态就**中止退出**，不会带着没写进去的内容走
4. 渲染进程无响应时 3 秒超时强制退出兜底

### 红绿灯关闭 / ⌘W

同样的三态确认（多脏标签时批量弹一次），保存失败不关。弹窗期间你按了 ⌘W 或有外部冲突弹窗插进来？旧弹窗会被视为「取消」安全收尾，绝不会出现「以为取消了、60 秒后应用带着你的修改暴毙」的情况。

## 数据都存在哪

| 内容 | 位置 |
|---|---|
| 你的笔记 | 你自己的目录（Notara 永远不复制、不搬家） |
| 粘贴的图片 | 笔记同目录 `assets/` |
| 主题设置 | `~/Library/Application Support/notara/settings.json` |
| 自定义主题 | `~/Library/Application Support/notara/themes/*.css` |
| 窗口状态 | `~/Library/Application Support/notara/window-state.json` |
| 最近工作区 | `~/Library/Application Support/notara/recent.json` |

卸载 Notara 不会动你的笔记。想彻底清除应用数据，删掉 `~/Library/Application Support/notara/` 即可。

## 常见问题

**Q：⌘N 新建的「未命名」文件，⌘S 没反应？**
未命名文件没有磁盘路径，⌘S 与 ⌘⇧S 都会弹出「另存为」对话框，选好位置即保存（之后 ⌘S 就是正常保存了）。

**Q：别的应用改了我的笔记，Notara 里没刷新？**
会自动刷新——但如果你这边也有未保存修改，会弹冲突确认框让你二选一，不会静默覆盖任何一边。

**Q：粘贴图片没反应？**
未保存的新文件不能收图（图片需要落到文件所在目录）。先 ⌘⇧S 保存，再粘贴。

**Q：导出的 HTML 双击打开是乱的？**
不会乱——样式与图片已全部内联进单文件，断网、发微信都能看。若公式/图表不显示，是 mermaid/KaTeX 的懒加载需要联网，属已知限制（见 v0.2 计划）。

**Q：dark 模式下界面是暗的，但代码块刺眼？**
这是主题 CSS 的问题，可用自定义主题微调（见[主题系统](#主题系统)）。

**Q：忘了保存就 ⌘Q 了，内容还在吗？**
在。⌘Q 会先自动写盘所有已保存过的文件；只有「未命名」文件会弹确认框拦住你，不会静默丢弃。

## 开发者指南

```bash
npm install          # 安装依赖
npm run dev          # 开发模式（热重载 + DevTools）
npm test             # 单元 + 组件测试（118 例）
npm run typecheck    # TS 双工程类型检查
npm run e2e          # 构建 + Playwright Electron 冒烟测试
npm run dist         # 构建 + electron-builder 打 dmg
```

架构概览：

```
src/
├── main/            # 主进程：窗口、菜单、服务层（文件/工作区/监听/图片/导出/主题/最近/状态）
│   └── services/    #   无状态服务函数 + 注入 userData 目录（便于单测）
├── preload/         # contextBridge：暴露 window.notara（23 个 IPC 方法，信封解包）
├── renderer/        # React 19 + zustand：UI、标签、编辑器、自动保存调度
└── shared/          # 主/渲染共享类型契约
tests/
├── unit/            # 主进程服务 + 渲染逻辑单测
├── component/       # React 组件测试（jsdom）
└── e2e/             # Playwright Electron 冒烟
```

安全基线：`nodeIntegration: false` / `contextIsolation: true` / `sandbox: true`，渲染进程零 Node API，全部通信走校验过的 IPC。

## 已知限制与 v0.2 计划

当前 v0.1 的已知限制：

- 本地构建无代码签名与公证（首次打开需手动放行）
- mermaid 图表与公式渲染的懒加载资源需联网
- 多窗口的窗口状态各自记录，互相覆盖最后关闭者
- 无工作区内全局搜索

v0.2 候选：帮助菜单、Word 导出（pandoc）、全局搜索、代码签名与 Homebrew 分发、asar 体积裁剪。
